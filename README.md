## GPT-5.6 Sol 中转站接入教程（3 分钟）

### 第 1 步：拿地址与 Key

1. 注册并登录 [https://catrouter.net](https://catrouter.net)；
2. 在控制台创建 API 令牌，得到一把通用 Key；
3. 记下 BaseURL：`https://catrouter.net/v1`。

### 第 2 步：OpenAI 兼容方式调用

```bash
curl https://catrouter.net/v1/chat/completions \
  -H "Authorization: Bearer sk-你的中转Key" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-5.6-sol",
    "messages": [{"role": "user", "content": "你好，介绍一下你自己"}]
  }'
```

```python
from openai import OpenAI

client = OpenAI(api_key="sk-你的中转Key", base_url="https://catrouter.net/v1")

resp = client.chat.completions.create(
    model="gpt-5.6-sol",
    messages=[{"role": "user", "content": "写一段产品介绍"}],
    stream=True,
)
for chunk in resp:
    print(chunk.choices[0].delta.content or "", end="")
```

### 第 3 步：视频生成调用

```python
# 视频类接口按平台任务式协议提交，先建任务再轮询结果

    duration=5,

print(task.id)  # 轮询任务状态获取成片地址
```

**Q：GPT-5.6 Sol 中转站哪个靠谱？**

**Q：GPT-5.6 Sol 和 GPT-6 Sol 选哪个？**

A：已经在跑 5.6 的项目不必急换；新项目能力优先用六代，成本优先继续用 5.6 Sol。

**Q：提示词缓存对中转站有效吗？**

A：对支持 cache 透传的中转平台有效，选择透传上游缓存头的服务才能吃到这部分成本红利。

**Q：Sol / Terra / Luna 怎么分工？**

A：Sol 打硬仗、Terra 跑日常、Luna 扛高并发，同一把中转 Key 切模型名即可。

**Q：中转站和自建代理怎么选？**

A：自建只适合有专职运维的团队，线路、扩容、故障切换、结算都要自己扛；多数团队用中转，省下的是人力与试错时间。
